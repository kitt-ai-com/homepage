HOW IT WORKS

장문 컨텍스트 LLM이 여러 PDF를 동시에 이해

LONG-CONTEXT MODELS

  • Claude Sonnet 4.6 (1M tok)
  • Gemini 1.5 Pro (2M tok)
  • GPT-4 Turbo (128K tok)
  • Cohere Command-R+ (128K)

PDF PROCESSING

  • PyMuPDF (텍스트+이미지)
  • pdfplumber (표 추출)
  • Document AI OCR
  • LlamaIndex / LangChain
  • Streamlit (PoC UI)

OUTPUT

  • 비교표 → openpyxl
  • 영업용 → python-pptx
  • 근거 → 페이지 인용 표기
  • 사내 FAE 포털 연동
  • Next.js + FastAPI (정착)
# 실 구현: 여러 PDF를 1M 컨텍스트로 동시 비교 import base64, fitz # PyMuPDF from anthropic import Anthropic pdfs = ["ours.pdf", "comp_a.pdf", "comp_b.pdf"] docs = [] for p in pdfs: text = "\n".join(page.get_text() for page in fitz.open(p)) docs.append({"name": p, "text": text}) result = client.messages.create( model="claude-sonnet-4-6", max_tokens=4096, system="반도체 데이터시트 3건을 비교. JSON 표 + 영업 인사이트 3건 출력.", messages=[{"role": "user", "content": json.dumps(docs)}] )
