# 실 구현: Google Sheets에서 1줄 셀로 즉시 번역 =GOOGLETRANSLATE(A2, "ko", "en") # 또는 Apps Script + DeepL Glossary로 시트 일괄 번역 function translateSheetWithGlossary() { const sheet = SpreadsheetApp.getActiveSheet(); const data = sheet.getDataRange().getValues(); const resp = UrlFetchApp.fetch("https://api.deepl.com/v2/translate", { method: "post", payload: { text: data.flat(), target_lang: "EN", glossary_id: "tp-semi-v2-1" # 사내 용어 사전 } }); sheet.getRange(1, data[0].length + 1, ...).setValues(parseDeepLResp(resp)); }
