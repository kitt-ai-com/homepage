HOW IT WORKS

n8n 노코드 워크플로 + 멀티채널 알림

MONITORING ENGINE

  • n8n self-hosted
  • Apache Airflow
  • cron / systemd
  • watchdog (파일 감시)
  • YAML 룰 엔진

NOTIFICATION CHANNELS

  • SMTP · Microsoft Graph
  • Slack Webhook
  • Teams Webhook
  • KakaoWork Bot API
  • SMS · Telegram (선택)

DASHBOARD

  • Grafana (실시간 차트)
  • Streamlit (PoC)
  • Next.js + WebSocket (정착)
  • InfluxDB / TimescaleDB
  • SSO 통합
