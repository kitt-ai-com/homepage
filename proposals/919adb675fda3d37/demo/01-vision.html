AI Vision 기반 불량 이미지 분석 자동화

반도체 다이·웨이퍼·PCB·현미경·열화상 이미지 내 불량 화소 및 결함 영역을 AI가 자동 탐지하고, 불량 위치·유형·면적·심각도·군집 패턴을 구조화 데이터로 변환하는 시스템을 구축합니다. 품질팀의 보고서 작성 시간을 줄이고, 과거 불량 이미지와의 유사도 비교를 통해 원인 분석 및 재발 방지 대응 속도를 높입니다.

STAGE 1
Rule 기반 1차 검출
dead pixel · hot pixel · stain · crack · burn mark을 OpenCV로 빠르게 검출
STAGE 2
AI Vision 모델 적용
YOLO v8 · Segment Anything · U-Net · Vision Transformer로 위치·면적·유형 분류
STAGE 3
보고 자동화
좌표·면적·심각도·이미지 crop·추정 원인·유사 과거 사례를 Excel/8D/품질 DB에 자동 저장

HOW IT WORKS

3단계 파이프라인 구현 스택

① RULE-BASED DETECTION

  • OpenCV (cv2)
  • Pillow / scikit-image
  • Adaptive Thresholding
  • Canny Edge Detection
  • Connected Components
  • DBSCAN (군집)

② AI VISION MODELS

  • YOLO v8 (객체 탐지)
  • Segment Anything (SAM)
  • U-Net (의료/반도체 특화)
  • Vision Transformer (ViT)
  • Claude / GPT-4o Vision (검증)
  • PyTorch / Ultralytics

③ REPORT + STORAGE

  • openpyxl · python-pptx
  • Chroma DB (이미지 임베딩)
  • PostgreSQL (품질 DB)
  • FastAPI + WebSocket
  • 사내 NAS · Google Drive
  • QE 8D 보고서 자동 생성
# 실 구현 예시: 3-Stage 파이프라인 통합 호출 import cv2, torch from ultralytics import YOLO from segment_anything import SamPredictor from sklearn.cluster import DBSCAN def analyze_defect_image(img_path): img = cv2.imread(img_path) # Stage 1: Rule-based 1차 검출 (OpenCV) candidates = opencv_detect(img) # dead/hot pixel·stain·crack # Stage 2: AI Vision으로 정밀 분류 yolo = YOLO("models/wafer_defect_v3.pt") detections = yolo.predict(img, conf=0.4) sam = SamPredictor(sam_model) masks = sam.predict(detections.boxes) # DBSCAN으로 군집 분석 clusters = DBSCAN(eps=8, min_samples=2).fit_predict(coords) # Stage 3: 유사 사례 검색 (임베딩) + 보고서 생성 similar = chroma.query(image_embedding, n_results=3) save_to_excel_and_8d(detections, clusters, similar) return {"defects": ..., "clusters": ..., "similar": ...}
