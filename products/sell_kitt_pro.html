상품 관리 CORE

  • 상품 코드 및 등급별 가격
  • 카테고리 계층 관리

상품 매칭 관리 CORE
다채널 상품명·옵션을 표준 상품에 매칭해, 발주서엔 공급사 기준 정확한 상품명이 출력됩니다.
  • 판매처 상품명 ↔ 표준 상품 매핑
  • 채널(쿠팡·스마트스토어 등) 구분 관리
  • 주문 상세에서 매칭 결과 즉시 확인
📦
자동 발주 시스템
공급사 양식에 자동으로 맞춰 발주서를 생성합니다. 매일 엑셀을 수정하던 번거로움을 없앱니다.
  • 공급사별 발주서 자동 생성
  • 상태별 필터 조회 및 검색
  • 배송·집계 엑셀 다운로드
💰
정산 자동화
수수료, 매입 원가를 반영한 순수익을 자동으로 계산. 수기 입력 오류를 완전히 제거합니다.
  • 공급사별 원가 지급 워크플로우
  • 셀러 수수료·정산 주기 개별 설정
  • 실시간 예정 / 내역 탭 전환
🚨
통합 CS 관리
주문 취소, 반품, 교환 처리를 한 곳에서 통합 관리. 클레임 현황을 대시보드에서 즉시 확인.
  • 클레임 미처리 건 알림
  • 반품·교환·취소 상태 관리
  • 셀러·문의 통합 처리
👥
셀러 & 공급사 관리
초대 코드 방식 온보딩, 등급·수수료 개별 설정. 예치금 충전식 거래처 발주·정산 지원.
  • 링크·코드 초대 (횟수·만료일 설정)
  • 사업자 등록 및 승인 워크플로우
  • 거래처 통합 대시보드
