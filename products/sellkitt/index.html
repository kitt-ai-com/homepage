THE PROBLEM

주문은 메신저에,
재고는 머릿속에.

식자재·소형 유통 현장의 주문은 여전히 카카오톡과 전화로 오갑니다. 같은 거래처가 매번 다른 형식으로 품목을 적어 보내고, 사장님은 그걸 일일이 엑셀에 옮겨 적으며 하루를 시작합니다.

주문을 옮기다 빠뜨리고, 재고는 감으로 관리되고, 월말 정산은 영수증 더미와 씨름하는 밤이 됩니다. Sellkitt는 이 흐름 전체를 하나의 자동화된 데이터 파이프라인으로 바꿉니다.

KEY FEATURES

핵심 기능

AI 엑셀 자동 업로드

거래처가 엑셀로 보낸 주문을 AI가 읽어 품목·수량·거래처까지 자동으로 업로드합니다. 양식이 제각각이어도 그대로 흡수합니다.

AI 채팅

상품·주문 조회부터 가격 수정, 주문서·리포트 생성까지. 채팅창에 말하듯 시키면 Sellkitt가 바로 처리합니다.

이미지 주문 추출

사진·캡처·손글씨로 온 주문도 AI가 이미지에서 품목과 수량을 추출해 주문에 자동으로 넣습니다.

발주부터 정산까지 한 번에

주문 접수 → 재고 차감 → 공급사 발주 → 정산까지, 흩어져 있던 과정을 한 흐름으로 자동 처리합니다.
